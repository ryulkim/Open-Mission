# 자동차 경주
## 입력
- [X] 콘솔 입력 받기
- [X] 쉽표 기준으로 구분
- [X] 시도할 횟수 입력 받기 및 숫자 변환

## 경주
- [X] 4 이상인 조건 만족하는 차 전진
- [X] 우승자 결정

## 출력
- [X] 자동차 이름 입력 안내 문구 출력
- [X] 시도할 횟수 질문 출력
- [X] 실행 결과 출력
- [X] 최종 우승자 결과 출력

## 예외 처리
- [X] 자동차 이름이 5자리 이하인지 확인
- [X] 시도 횟수가 0회 이하일 경우, 예외를 발생시킨다
- [X] 공백을 입력했을 경우, 예외를 발생시킨다
- [X] 동일한 이름의 자동차가 존재할 경우, 예외를 발생시킨다
