# 자동차 경주

## 목표

여러 명이 할 수 있는 레이싱 게임 만들기(유사 경마게임)

### 세부 목표

1. 유지보수 좋은 코드 작성(ex: 팩토리 패턴 등 디자인 패턴 적용)
2. 안정성 있는 게임 만들기(테스트 코드 작성)
3. 새로운거 공부해보기

## 레이싱 게임

게임 모드

1. 혼자하는 경마 게임
    1) 현재 자동차(경마) 리스트
    2) 자동차 선택
    3) 커스텀 자동차 추가
2. 멀티 플레이 경마 게임

자동차 스펙

- 공식:속도*(0~운빨 최대치) (만약, 값이 같은게 존재할 경우, 파워 수치로 순위 결정, 그것도 같을 경우 (0~운빨 최대치 값으로 랜덤 값 추출 후 결정))
- 속도 (Integer 범위)
- 파워 (최대 1000)
- 운빨(버프/디버프) 최대치 (최대 100까지)

레이싱카 종류

1. 기본 카
    - 속도 (0~100)
    - 파워 (최대 100)
    - 운빨 최대치 (최대 100까지)
2. 트롤 카
    - 속도 (-100~5)
    - 파워 (최대 100)
    - 운빨 최대치 (최대 10000까지)
3. 트럭
    - 속도 (-10~50)
    - 파워 (최대 10000)
    - 운빨 최대치 (최대 200까지)

```

1-1. 혼자하는 모드일 경우

```

## 프로그래밍 조건

- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다. (메소드 분리할 것)
- 3항 연산자를 쓰지 않는다.
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.
- 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다.
- 테스트 코드를 쓴다.
- else, switch/case 예약어를 쓰지 않는다 (if 안에 return 방식을 쓴다.)
